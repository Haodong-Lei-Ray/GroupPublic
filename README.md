# GroupPublic · 入群指引

本目录用于存放**对外公开的入群材料**。想加入交流群的同事/同学，请按下面步骤操作。

## 扫码入群（微信）

1. 打开本目录下的图片：**[`vibecoding.jpg`](./vibecoding.jpg)**
2. 使用 **微信** 扫一扫（可长按图片识别，或保存到手机后用微信扫）
3. 按提示加入群聊：**VibeCodingMind**

![入群二维码](./vibecoding.jpg)

> **说明：** 微信入群二维码通常 **7 天内有效**，过期后需重新生成并更新本目录中的 `vibecoding.jpg`。若扫码失败，请联系仓库维护者索取最新二维码。

## 文件说明

| 文件 | 用途 |
|------|------|
| `vibecoding.jpg` | 微信群入群二维码（主入口） |
| `README.md` | 本说明 |

## 在线查看（GitHub / 代码托管）

若你在网页上浏览本仓库，可直接点开 [`vibecoding.jpg`](./vibecoding.jpg) 查看大图，再用手机微信扫描屏幕上的二维码。
